# 🚀 Day Courier Simulator: Мотивация через штрафы

**Тип:** Консольная симуляция дня курьера с геймификацией
**Цель:** Трансформировать негативный опыт работы курьером в мотивацию для изучения Go

---

## 📖 Концепция

Этот модуль — художественная симуляция одного дня из жизни курьера, основанная на реальном опыте автора. Программа превращает ежедневные трудности курьерской работы (штрафы, негативные реакции пассажиров, усталость) в мотивационный инструмент для изучения Go.

### 🎯 Философская основа:
- **Каждый штраф** = +1 к мотивации учить Go
- **Каждый презрительный взгляд** = напоминание о цели стать разработчиком
- **Каждая усталость** = энергия для следующей сессии кодинга

---

## 🎮 Геймплей

### 📅 Этапы дня:
1. **🌅 Утро (11:00)** — Подготовка к рабочему дню
2. **🛵 Рабочий день** — Принятие и выполнение 3 заказов
3. **🌙 Вечер** — Подведение итогов и геймификация
4. **🤔 Философские выводы** — Рефлексия и мотивация

### 📦 Типы заказов:
1. **Короткий районный заказ (случайный)** — 300 руб
2. **Собачий корм Фестивальная → Митино** — 450 руб (метро + автобус)
3. **Бескаркасное кресло-груша Сокол → Левобережный** — 500 руб (крупногабаритный)

## 🏆 Геймификация и достижения

### 🎯 Система очков:
```
Очки = Выполненные заказы × 100
      - Отменённые заказы × 50
      + Заработок / 10
      - Штрафы / 5
      - Психологическая нагрузка / 2
```

### 🏅 Достижения:
- **🏅 Мастер доставки** — Выполнить 2+ заказа
- **💰 Без штрафов** — Ноль отмен и штрафов
- **💪 Выдержал давление** — Высокая психологическая нагрузка (>50)
- **🚀 Высокий доход** — Заработать 1000+ руб
