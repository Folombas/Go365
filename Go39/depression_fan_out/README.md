# ⚡ День 39: Fan-out распределение депрессивной энергии

**Модуль Day 39 марафона "100DaysGo: Reboot"**

## 🧠 Концепция модуля

Программа демонстрирует паттерн **Fan-out** в контексте **распределения ограниченных психических ресурсов** (энергии/воли) на множество задач (поездок на транспорте).

**Продолжение Day 38 (Fan-in):**
*Вчера собирали энергию → Сегодня распределяем её*

```

Источник энергии → Канал задач → Пул воркеров → Параллельное выполнение → Сбор результатов

```

## 🏗️ Архитектура решения

### Основные компоненты:

| Компонент          | Описание                              |
|--------------------|---------------------------------------|
| **`EnergySource`** | Общий ресурс (энергия Гоши), защищен `sync.Mutex` |
| **`TransportTask`**| Задача поездки с энергозатратами     |
| **`Worker`**       | Горутина-воркер, берет задачи из канала |
| **`Каналы`**       | Распределение задач + сбор результатов |
| **`WaitGroup`**    | Ожидание завершения всех воркеров    |

## 🔧 Технические особенности Fan-out

1. **Фиксированный пул воркеров** (3 горутины)
2. **Общий канал задач** (`tasks`)
3. **Конкурентный доступ** к энергии (`sync.Mutex`)
4. **Гонка за ресурсы** между воркерами
5. **Элегантное завершение** (закрытие канала)

```go
// Fan-out реализация
for i := 0; i < numWorkers; i++ {
    go worker(i, tasks, energySource, results, &wg)
}
```


## 🧩 Психологическая метафора

| Go Концепция | Психологическая аналогия |
| :-- | :-- |
| **Fan-out** | Распределение последних сил на полезные действия |
| **Воркеры** | Остатки "силы воли" |
| **Mutex** | Защита от одновременного истощения |
| **Конкуренция** | Борьба желаний за ограниченные возможности |
| **WaitGroup** | Обязательство завершить начатое |

## 📊 Сравнение Fan-in vs Fan-out

| Характеристика | **Day 38: Fan-in** | **Day 39: Fan-out** |
| :-- | :-- | :-- |
| **Направление** | Сходится к одному результату | Расходится от одного источника |
| **Применение** | Финальная агрегация | Начальное распределение |
| **Ресурсы** | Собирает разрозненные | Распределяет ограниченные |
| **Сложность** | Низкая | Средняя (конкуренция) |
| **Метафора** | Сбор мыслей в поток | Распределение энергии по задачам |

## 💻 Код демонстрации

```go
func main() {
    energySource := NewEnergySource(20)  // 20 единиц энергии
    tasks := make(chan *TransportTask, 10)
    results := make(chan *TaskResult, 10)
    var wg sync.WaitGroup

    // Fan-out: запускаем 3 воркера
    for i := 0; i < 3; i++ {
        wg.Add(1)
        go worker(fmt.Sprintf("W%d", i), tasks, energySource, results, &wg)
    }

    // Генерируем задачи
    go generateTasks(tasks, 6)
    close(tasks)

    wg.Wait()
    close(results)
}
```
