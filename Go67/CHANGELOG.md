**Новые функции:**

## 🐛 Известные проблемы

### Текущие ограничения

1. **Хранение данных**
   - Прогресс хранится в памяти (map[int64]*Player)
   - При перезапуске бота данные теряются
   - **Решение в будущем:** База данных (PostgreSQL/SQLite)

2. **Обработка ошибок**
   - Минимальная валидация ввода
   - **Решение в будущем:** Добавить обработку edge cases

3. **Ограничения Telegram**
   - Лимит на длину сообщения (4096 символов)
   - Лимит на callback_data (64 байта)
   - **Решение в будущем:** Пагинация, сокращение данных
