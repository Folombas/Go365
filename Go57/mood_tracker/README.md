# MoodMeter — Дневник эмоций на Go

**Модуль:** Go57/mood_tracker  
**Автор:** Гоша (участник Go365)  
**Дата:** 26 февраля 2026 года  

## Описание

MoodMeter — это веб-приложение для отслеживания эмоционального состояния, созданное с использованием стандартной библиотеки Go `net/http` и шаблонов `html/template`. Проект вдохновлён сегодняшним днём Гоши: депрессия, прогулка по парку и мамины пирожки. Приложение позволяет:

- Записывать своё настроение (от "Ужасное" до "Отличное").
- Добавлять заметки о том, что повлияло на состояние.
- Накапливать игровые очки опыта (EXP) за каждую запись.
- Получать достижения за регулярность и количество записей.
- Просматривать статистику и историю настроений.

## Требования

- Go 1.16 или выше
- Порт 8080 свободен

## Установка и запуск

```bash
cd Go57/mood_tracker
go mod tidy
go run main.go
