## 🐛 Проблемы и решения

### Проблема 1: Ошибки компиляции Ebiten API
**Ошибка:** `op.Geo` не существует в новой версии Ebiten
**Решение:** Заменено на `op.GeoM` (GeoMatrix)

### Проблема 2: Несовместимость типов float32/float64
**Ошибка:** Многочисленные ошибки при передаче координат
**Решение:** Явное преобразование типов через `float32()`

### Проблема 3: Отсутствие `color.Yellow` и `color.Red`
**Ошибка:** В Go нет предопределённых констант цвета
**Решение:** Использованы `color.RGBA{255, 255, 0, 255}` и `color.RGBA{255, 0, 0, 255}`

### Проблема 4: Интерфейс ebiten.Game
**Ошибка:** Missing method Layout
**Решение:** Добавлен метод `Layout()` возвращающий ScreenWidth, ScreenHeight

### Проблема 5: Дублирующиеся функции
**Ошибка:** `drawMenu` и `updateMenu` объявлены дважды
**Решение:** Удалены дубликаты, оставлены рабочие версии
