# Go50: Symbiosis Balancer — программирование и видеомонтаж

## 📌 Название модуля
**`symbiosis-balancer`** — программа, демонстрирующая связь между изучением Go и видеомонтажом, с подсчётом дней и XP.

## 🎯 Описание
Этот модуль показывает, как творчество и программирование могут дополнять друг друга. Используя `go:embed`, мы встроили легенду дня и мотивационные фразы, которые напоминают: программисты создают инструменты для монтажа, а монтажёры вдохновляют программистов.

Каждый запуск:
- Выводит легенду дня (метель, CapCut, подписчики во Вьетнаме).
- Считает дни программирования (с 18.01.2026) и дни монтажа (с 18.02.2026).
- Начисляет XP (10 за день программирования, 5 за день монтажа) и определяет уровень.
- Показывает 10 мыслей о симбиозе.
- Хвалит Гошу за баланс.

## 🚀 Запуск

cd Go50/symbiosis-balancer
