# 📊 Отчёт - День 95 (5 апреля 2026)

## 🎯 Тема дня: Game Collection - 3 игры + Menu Launcher

Сегодня был создан полноценный набор из 3 различных игр на Go с использованием Ebitengine, плюс главное меню для выбора игры.

## 🎮 Созданные игры

### 1. 💣 Bomberman
- **Жанр:** Аркадная игра
- **Механика:** Постановка бомб, разрушение стен, уничтожение врагов
- **Особенности:**
  - 5 уровней с процедурной генерацией
  - 3 типа врагов (balloon, ghost, slime)
  - 3 типа улучшений (бомбы, огонь, скорость)
  - Система жизней и очков
  - Камера следит за игроком

### 2. ♟️ Checkers (Шашки)
- **Жанр:** Настольная игра
- **Механика:** Полные правила русских шашек
- **Особенности:**
  - Обязательное взятие
  - Дамки ходят на любое расстояние
  - AI с алгоритмом Minimax + Alpha-Beta pruning
  - Объёмные спрайты с градиентами
  - Подсветка допустимых ходов

### 3. 🧩 Puzzle (Пятнашки)
- **Жанр:** Головоломка
- **Механика:** Сетка 4x4, перемещение плиток
- **Особенности:**
  - Гарантированно решаемое перемешивание
  - 3 уровня сложности
  - Градиентные цветные плитки (HSL)
  - Подсчёт ходов

### 4. 🎮 Menu Launcher
- **Назначение:** Главное меню для выбора игр
- **Управление:** Мышь + клавиатура
- **Запуск:** Через `go run`
