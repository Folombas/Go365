## 🎯 Тема дня: Game Collection - 3 игры + Menu Launcher

Сегодня был создан полноценный набор из 3 различных игр на Go с использованием Ebitengine, плюс главное меню для выбора игры. Все спрайты программно сгенерированы, никаких внешних ассетов.

## ✅ Выполненные задачи

### 1. 💣 Bomberman v1.0.0
**Статус:** ✅ Завершено

**Что сделано:**
- Создана архитектура с чистым разделением на пакеты: `game`, `entity`, `level`, `sprite`
- Реализован полноценный state machine: Menu → Playing → Paused → GameOver/LevelComplete/Victory
- Механика бомб: таймер 2 секунды, анимация пульсации (3 кадра)
- Система взрывов: распространение в 4 направлениях, разрушение стен
- 2 типа стен: разрушимые (кирпичи) и неразрушимые (камень)
- 3 типа врагов с разным поведением и скоростью:
  - Balloon: быстрый (2.0)
  - Ghost: средний (1.5)
  - Slime: медленный (1.0)
- 3 типа улучшений:
  - 🔴 Bomb Up: +1 к макс. бомбам
  - 🔥 Flame Up: +1 к дальности взрыва
  - ⚡ Speed Up: +0.5 к скорости
- Процедурная генерация 5 уровней (11×11 → 21×21)
- Система жизней (3 жизни) с неуязвимостью после урона
- Камера с плавным следованием за игроком
- Все спрайты программно сгенерированы через `image.NewRGBA`

**Файлы:**
- `bomberman/cmd/game/main.go` - Точка входа
- `bomberman/internal/game/game.go` - Игровой цикл (~750 строк)
- `bomberman/internal/entity/entity.go` - Сущности (~250 строк)
- `bomberman/internal/level/level.go` - Генерация уровня (~180 строк)
- `bomberman/internal/sprite/sprite.go` - Спрайты (~500 строк)

**Управление:** WASD/Стрелки + SPACE для бомбы

### 2. ♟️ Checkers (Шашки) v1.0.0
**Статус:** ✅ Завершено

**Что сделано:**

  - Обычные шашки бьют назад
  - Серия взятий
- AI с алгоритмом Minimax + Alpha-Beta pruning (глубина 3)
- Оценка позиции: материал, продвижение вперёд, контроль центра
- Игрок за белых, AI за чёрных
- Объёмные спрайты шашек с градиентами и тенями
- Дамки с золотой короной
- Доска 8×8 с текстурой дерева
- Подсветка выбранной шашки и допустимых ходов

**Файлы:**
- `checkers/cmd/game/main.go` - Точка входа
- `checkers/internal/game/game.go` - Игровой цикл (~400 строк)
- `checkers/internal/board/board.go` - Логика доски (~280 строк)
- `checkers/internal/ai/ai.go` - AI Minimax (~180 строк)
