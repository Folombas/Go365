# 📋 PLAN - Go365 Day 95 (5 апреля 2026)

## 🎯 Цель дня
Создать коллекцию из 3 игр на Go с использованием Ebitengine, продемонстрировав продвинутое владение языком Go и игровым дизайном.

## 🎮 Игры для разработки

### 1. 💣 Bomberman
**Концепция:** Классическая аркадная игра с бомбами
**Механики:**
- Постановка бомб с таймером
- Разрушаемые и неразрушимые стены
- Система взрывов с распространением огня
- 3 типа врагов (balloon, ghost, slime) с разным поведением
- 3 типа улучшений (больше бомб, дальше взрыв, быстрее бег)
- Процедурная генерация уровней (5 уровней с нарастающей сложностью)
- Система жизней и очков

**Архитектура:**
```
bomberman/
├── cmd/game/main.go           # Точка входа
├── internal/
│   ├── game/game.go           # Игровой цикл, состояния, ввод
│   ├── entity/entity.go       # Player, Bomb, Explosion, Enemy, PowerUp
│   ├── level/level.go         # Генерация уровня
│   └── sprite/sprite.go       # Программная генерация спрайтов
└── assets/sprites/            # Папка для спрайтов
```

**Управление:** WASD/Стрелки + SPACE для бомбы

### 2. ♟️ Checkers (Шашки)
**Концепция:** Классическая настольная игра против AI
**Механики:**
- Полная логика русских шашек
- Обязательное взятие
- Дамки ходят на любое расстояние
- Обычные шашки бьют назад
- AI с алгоритмом Minimax + Alpha-Beta pruning (глубина 3)
- Оценка позиции: материал, продвижение, центр

**Архитектура:**
```
checkers/
├── cmd/game/main.go           # Точка входа
├── internal/
│   ├── game/game.go           # Игровой цикл, ввод, отрисовка
│   ├── board/board.go         # Логика доски, ходы, правила
│   ├── ai/ai.go               # AI (Minimax)
│   └── sprite/sprite.go       # Спрайты шашек
└── assets/sprites/            # Папка для спрайтов
```

**Управление:** Клик мышью

### 3. 🧩 Puzzle (Пятнашки)
**Концепция:** Классическая головоломка 4x4
**Механики:**
- Сетка 4x4 с 15 пронумерованными плитками
- Перемешивание гарантированно решаемое (из решённого состояния)
- 3 уровня сложности (50/100/200 ходов перемешивания)
- Подсчёт ходов
- Градиентные цветные плитки (HSL цветовое пространство)

**Архитектура:**
```
puzzle/
├── cmd/game/main.go           # Точка входа
├── internal/
│   ├── game/game.go           # Игровой цикл, ввод, отрисовка
│   ├── puzzle/puzzle.go       # Логика пазла
│   └── sprite/sprite.go       # Спрайты плиток
└── assets/sprites/            # Папка для спрайтов
```

**Управление:** Клик мышью, R - перемешать

### 4. 🎮 Menu (Лаунчер)
**Концепция:** Главное меню для выбора игр
**Механики:**
- Красивый интерфейс с иконками
- Навигация мышью и клавиатурой
- Запуск игр через `go run`

## 🏗️ Технические детали

### Стек
- **Язык:** Go 1.25.0
- **Движок:** Ebitengine v2.8.0
- **Графика:** Программная генерация спрайтов (image package)
- **Архитектура:** Clean internal packages

### Принципы
- Каждый проект - отдельный модуль
- Чистая архитектура внутри каждого проекта
- Разделение логики: game, entity/board, sprite, render
- Все спрайты генерируются программно через `image.NewRGBA`
- Обработка состояний через enum-подобные константы

### Go практики
- Структуры с методами (OOP)
- Интерфейсы где уместно
- Пакетная организация кода
- Обработка ошибок
- Константы для магических чисел
- Комментарии на русском языке
