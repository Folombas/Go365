# 🚀 Canceled Order Motivation - Day 20

## 📖 Описание модуля
Трагикомичная симуляция дня курьера-разработчика Гоши, который через отмененные заказы и потерю времени приходит к осознанию важности изучения языка программирования Go и поиска баланса между работой и хобби (съёмка видео и монтаж).

## 🎯 Цели модуля
- Демонстрация вероятностных событий в программировании
- Практика работы со структурами и методами в Go
- Симуляция принятия решений на основе условий
- Мотивация к систематическому изучению Go

## 🎬 Сюжетная линия
Гоша — курьер, который мечтает стать Go-разработчиком и увлекатеся видео-творчеством. Его день состоит из:
1. **Утреннего хаоса** — поздний подъем, отмененные заказы
2. **Рабочего марафона** — поездки по Москве и Химкам
3. **Финансового подсчета** — анализ заработка и потерь времени
4. **Вечерних размышлений** — баланс между Go и видеомонтажом
5. **Мечтаний** — несмонтированные travel-влоги с Филиппин

## ⚙️ Технические особенности

### Основные компоненты:
1. **Структура DailyResult** — хранение результатов дня
2. **Вероятностные функции** — симуляция отмены заказов (40% шанс)
3. **Система мотивации** — 10 уникальных мотивационных фраз
4. **Балансировщик времени** — рациональное распределение времени

### Ключевые алгоритмы:
- Расчет заработка на основе случайных чисел
- Определение уровня мотивации
- Принятие решений об установке CapCut
- Балансировка времени обучения
