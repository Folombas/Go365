# WSL Go Environments Analyzer

**Модуль:** Go56/wsl_go_environments  
**Версия:** 2.0.0 (актуальный список WSL-дистрибутивов на 25.02.2026)  
**Автор:** Гоша (участник челленджа Go365)  
**Дата:** 25 февраля 2026 года  

## Описание

Консольная утилита на Go для анализа всех доступных в WSL дистрибутивов Linux с точки зрения Go-разработчика. Программа выводит таблицу с оценками поддержки Go, совместимости с ИИ-инструментами (Qwen CLI, DeepSeek CLI) и командами установки. Каждый дистрибутив приносит очки опыта (EXP), а полный анализ даёт ачивку «Знаток WSL».

## Требования

- Go 1.16+
- Windows с WSL2 (для установки дистрибутивов)

## Установка и запуск

```bash
git clone https://github.com/Folombas/go365.git
cd go365/Go56/wsl_go_environments
go mod tidy
go run main.go
