## Описание

Консольная утилита на Go, которая помогает выбрать операционную систему для установки DeepSeek CLI (и других ИИ-кодогенераторов) на основе текущего окружения. Программа определяет ОС, выдаёт рекомендацию и добавляет немного овощного юмора из сегодняшних покупок Гоши.

## Установка и запуск

```bash
cd Go55/cli_habitat_advisor
go run main.go
