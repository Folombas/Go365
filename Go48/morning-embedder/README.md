# Go48: Morning Embedder — go:embed и утренняя прокачка

## 📌 Название модуля
**`morning-embedder`** — программа, демонстрирующая директиву `go:embed` для встраивания текстовых файлов в бинарник.

## 🎯 Описание
Этот модуль показывает, как:
- Встраивать файлы (`legend.txt`, `deepseek_motivation.txt`) с помощью `//go:embed`.
- Выводить встроенный текст в консоль.
- Подсчитывать дни без CapCut и XP.
- Использовать встроенные ресурсы для геймификации и мотивации.

Каждый запуск:
1. Выводит легенду дня из встроенного файла.
2. Считает дни с 18.01.2026.
3. Начисляет XP (10 за день + бонус).
4. Выводит 10 мотивационных фраз про DeepSeek V4.
5. Хвалит Гошу за утренний подвиг.

## 🚀 Запуск

cd Go48/morning-embedder
