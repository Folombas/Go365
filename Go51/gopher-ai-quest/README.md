# Go51: Gopher AI Quest — Go в мире нейросетей

## 📌 Название модуля
**`gopher-ai-quest`** — программа, объединяющая подсчёт дней обучения, прокачку персонажа и факты о роли Go в сфере искусственного интеллекта.

## 🎯 Описание
Этот модуль демонстрирует:
- Встраивание текстовых файлов через `go:embed`.
- Подсчёт дней с фиксированной даты (18.01.2026).
- Геймификацию: XP, уровни, достижения.
- Мотивационные факты о Go и AI (OpenCode, Ollama, TensorFlow и др.).

Каждый запуск:
1. Выводит легенду дня (пшёнка, Snickers, метель).
2. Считает дни обучения и XP.
3. Показывает разблокированные достижения.
4. Даёт 10 фактов о Go в мире AI.
5. Хвалит Гошу и напоминает про дисклеймер.

## 🚀 Запуск
```bash
cd Go51/gopher-ai-quest
go run main.go
