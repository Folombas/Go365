# Go40: Трагикомичный конвейер дней без CapCut

## 🎯 Описание модуля
Трагикомичная реализация паттерна **Pipeline (Конвейер)** на Go, подсчитывающая дни после удаления CapCut для полной фокусировки на обучении Go и Go-стека. Программа представляет собой игровую метафору пути Go-разработчика, где каждый день без отвлекающего софта - это "прокачка" навыков.

## 🏗️ Архитектура конвейера
1. **Генератор дат** (`generateDatePipeline`) - горутина, создающая поток дней с 18.01.2026
2. **Подсчётчик сопротивления** (`countResistanceDays`) - фильтрует и считает дни
3. **Генератор саги** (`displaySaga`) - создаёт эпическое повествование дня
4. **Система достижений** (`awardAchievements`) - игровая прокачка с мотивацией
