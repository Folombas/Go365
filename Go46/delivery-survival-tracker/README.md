# Go45: Delivery Survival Tracker — os, bufio и учёт выживания

## 📌 Название модуля
**`delivery-survival-tracker`** — программа для учёта доходов от доставок, дней без CapCut и мотивации учить Go с использованием пакетов `os` и `bufio`.

## 🎯 Описание
Этот модуль демонстрирует:
- **os** — работа с файлами (открытие, создание).
- **bufio** — буферизованное чтение и запись строк.
- **Сохранение статистики** в текстовый файл с разделителями.
- **Взаимодействие с пользователем** через стандартный ввод.
- **Геймификацию**: XP за каждый день учёбы и за заработанные рубли.

Каждый запуск:
1. Проверяет, запускалась ли программа сегодня.
2. Если нет — спрашивает доход, обновляет дни без CapCut и XP.
3. Сохраняет данные в `delivery_stats.txt`.
4. Выводит легенду дня, мотивационные фразы и похвалу.
