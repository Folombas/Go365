## 🕹️ МЕХАНИКИ ИГРЫ

### Персонаж (структура `Player`)
У Гоши есть 4 основные характеристики:
- **Фокус** (`Focus`) — способность концентрироваться. Падает от рутины, растёт от учёбы.
- **Выносливость** (`Stamina`) — физический ресурс. Тратится на заказы.
- **Знание Go** (`Knowledge`) — главный навык для побега из курьерства. Растёт медленно.
- **Мотивация** (`Motivation`) — эмоциональный фон. Критически важна.

### Игровой цикл
1.  **Утренняя депрессия** (`MorningDepression()`) — случай определяет, поднимется ли Гоша.
2.  **Три выбора за день** (`MakeChoice()`) — каждый влияет на статистику.
3.  **Финальный отчёт** — итоги дня и совет на завтра.

### Ключевые методы
- `WorkAsCourier()` — симуляция изматывающей работы. Деньги 💰, но падение мотивации.
- `StudyGo()` — процесс обучения. Сложно, но даёт долгосрочный рост.
- `TinkerWithN8n()` — отвлечение, которое тоже даёт + к кругозору.
