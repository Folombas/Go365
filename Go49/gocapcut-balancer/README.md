# Go49: gocapcut-balancer — CLI для баланса между Go и видео-монтажом (Cobra)

## 📌 Название модуля
**`gocapcut-balancer`** — консольное приложение для учёта времени, потраченного на программирование и монтаж, с использованием библиотеки Cobra.

## 🎯 Описание
Этот модуль демонстрирует создание многофункционального CLI с помощью Cobra. Команды:
- `study [минуты]` — записать время учёбы Go.
- `edit [минуты]` — записать время монтажа.
- `status` — показать баланс и XP.
- `deepseek` — отсчёт до выхода DeepSeek V4.

## 🚀 Запуск
```bash
cd Go49/gocapcut-balancer
go run main.go [команда]
