# GoNewsBot – Telegram-бот для IT-новостей о Go

**Модуль:** Go61/gonews_bot  
**Автор:** Гоша (участник Go365)  
**Дата:** 2 марта 2026 года  

## Описание

Этот Telegram-бот собирает свежие новости о языке Go и Go-стеке из нескольких RSS-источников за последние 4 часа. Бот предоставляет простой интерфейс с одной кнопкой "Fresh IT News". Реализована геймификация: за каждый запрос начисляются EXP, растёт уровень, ведётся статистика.

## Команды

- `/start` – приветствие и кнопка для получения новостей.
- `/stats` – статистика пользователя (уровень, EXP, количество запросов).
- `/help` – справка.

## Используемые RSS-ленты

- [Официальный блог Go](https://go.dev/blog/feed.atom)
- [Хабр (Go)](https://habr.com/ru/hub/go/rss/)
- [Reddit r/golang](https://www.reddit.com/r/golang/.rss)
- [Golang Weekly](https://golangweekly.com/rss)
- [Блог Джона Кэлхауна](https://www.calhoun.io/feed)

## Установка и запуск

1. Получите токен у [@BotFather](https://t.me/botfather).
2. Скопируйте `.env.example` в `.env` и вставьте токен.
3. Установите зависимости: `go mod tidy`
4. Запустите: `go run main.go`

Для постоянной работы на сервере скомпилируйте бинарник и настройте systemd.

## Геймификация

- За каждый запрос новостей: **+5 EXP**.
- Уровень = floor(EXP/50) + 1.
- Статистика сохраняется в `users.json`.
