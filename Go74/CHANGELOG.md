### 3. Система очков навыков

**Заработок:**
- **За уровень:** 2 + (уровень / 5) очков
  - Уровень 1-4: 2 очка
  - Уровень 5-9: 3 очка
  - Уровень 10-14: 4 очка
  - Уровень 15+: 5 очков
  
- **За квесты:** 1-3 очка (в зависимости от квеста)

**Трата:**
- **1 очко:** Основы Go, Мастер Фокуса
- **2 очка:** Конкурентность, Интерфейсы, Медитация, Борьба с прокрастинацией, Сила Воли, Управление деньгами
- **3 очка:** Web Фреймворки, Базы данных, Дисциплина
- **4 очка:** Микросервисы

### 5. Бонусы к характеристикам

**Применение бонусов:**
```go
func (st *SkillTree) GetTotalBonus(bonusType string) int {
    total := 0
    for _, skill := range st.Skills {
        if skill.BonusType == bonusType {
            total += skill.Level * skill.BonusValue
        }
    }
    return total
}
```

**Пример:**
```
Игрок имеет:
- Основы Go: ур. 3 → +15 Знание Go
- Конкурентность: ур. 2 → +16 Знание Go
- Мастер Фокуса: ур. 4 → +20 Фокус

Итого:
- Знание Go: +31
- Фокус: +20
```

## 📊 База данных

### Таблица `skill_trees`
```sql
CREATE TABLE skill_trees (
    chat_id INTEGER PRIMARY KEY,
    skill_points INTEGER DEFAULT 0,
    total_points INTEGER DEFAULT 0,
    FOREIGN KEY (chat_id) REFERENCES players(chat_id) ON DELETE CASCADE
)
```

### Таблица `skills`
```sql
CREATE TABLE skills (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    chat_id INTEGER NOT NULL,
    skill_id TEXT NOT NULL,
    level INTEGER DEFAULT 0,
    unlocked INTEGER DEFAULT 0,
    FOREIGN KEY (chat_id) REFERENCES players(chat_id) ON DELETE CASCADE,
    UNIQUE(chat_id, skill_id)
)
```
