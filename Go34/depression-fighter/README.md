# День 34: Битва с Внутренним Хаосом

## 📖 Легенда
Гоша просыпается с депрессией, но день должен быть прожит. Через призму пакета `sync` мы моделируем борьбу с внутренним беспорядком.

## 🎯 Цель
Освоить базовые примитивы синхронизации на примере "задач дня":
- `sync.Mutex` для защиты общего состояния
- `sync.WaitGroup` для ожидания завершения
- `sync/atomic` для атомарных операций
