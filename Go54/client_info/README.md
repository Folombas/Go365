# Client Info — Информация о пользователе 🕵️‍♂️

**Версия:** 1.0.0  
**Автор:** Гоша (в рамках ежедневного квеста Go365)  
**Дата создания:** 23 февраля 2026 года  

## Описание

Это веб-приложение на Go, которое определяет и отображает информацию о клиенте, подключившемся к серверу:

- 🖥️ **Операционная система** (Windows, macOS, Linux, Android, iOS и др.)
- 🌐 **Веб-браузер** (Chrome, Firefox, Safari, Edge, Opera и др.)
- ⏱️ **Время входа** (точная дата и время запроса)

Приложение создано Гошей после ночного эксперимента с Qwen CLI. Оно помогает понять аудиторию и может служить основой для сбора статистики.  

В игровой вселенной Go365 этот модуль даёт **+200 очков опыта** и открывает навык **«Клиентская аналитика»**.

## Требования

- Go 1.16 или выше (рекомендуется 1.20+)
- Доступный порт `8081` (можно изменить в коде)
