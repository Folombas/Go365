## 🎬 Сюжетная линия

**28 января 2026. 10:30 утра.** Гоша просыпается после 7.5 часов сна. За окном - снежная метель, в душе - метель мыслей: "Зачем всё это? Может, бросить Go и смотреть сериалы?"

Но вместо этого он включает компьютер и начинает битву. Сегодняшний день - идеальная метафора для изучения горутин: несколько задач выполняются параллельно, некоторые успешно, некоторые отменяются, но **главная задача (обучение) продолжается!**

### 🎯 Цель дня: **Понять горутины через историю выживания**
