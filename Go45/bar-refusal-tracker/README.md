# Go45: Bar Refusal Tracker — flag, time и статистика сопротивления

## 📌 Название модуля
**`bar-refusal-tracker`** — программа для учёта дней без социальных отвлечений (бары, клубы, тусы) и дней без CapCut с использованием пакетов `flag` и `time`.

## 🎯 Описание
Этот модуль демонстрирует:
- **flag** — разбор аргументов командной строки (`-days`, `-bar-days`, `-name`).
- **time** — работа с датами, подсчёт дней между датами.
- **JSON** — сохранение статистики между запусками.
- **Геймификацию**: XP за каждый день без бара и без CapCut.

Каждый запуск:
1. Загружает статистику из `resistance.json` (или создаёт новую).
2. Вычисляет дни без CapCut с 18.01.2026.
3. Обновляет дни непрерывного отказа от бара (если это первый запуск — начинает отсчёт с сегодня).
4. Начисляет XP (10 за день без CapCut, 5 за день без бара).
5. Сохраняет обновлённые данные.
6. В зависимости от флагов выводит либо только числа, либо полную легенду.

## 🚀 Запуск
```bash
cd Go45/bar-refusal-tracker
go run main.go               # полный отчёт
go run main.go -days         # только дни без CapCut
go run main.go -bar-days     # только дни без бара
go run main.go -name="Гоша"  # с персонализацией
