# Go52: OpenCode Install Quest — все способы установки AI-агента на Go

## 📌 Название модуля
**`opcode-install-quest`** — программа, объединяющая легенду дня, подсчёт дней и XP, а также полный справочник по установке OpenCode.

## 🎯 Описание
Этот модуль демонстрирует:
- Встраивание текстовых файлов через `go:embed`.
- Подсчёт дней с фиксированной даты (18.01.2026).
- Геймификацию: XP, уровни, достижения.
- Интерактивный гайд по установке OpenCode (6 способов + нюансы для Windows).

Каждый запуск:
1. Выводит легенду дня (солнце, каша под ногами, радость от OpenCode).
2. Считает дни обучения и XP (с бонусом за открытие).
3. Показывает разблокированные достижения.
4. Даёт полную таблицу методов установки OpenCode.
5. Хвалит Гошу и напоминает про дисклеймер.

## 🚀 Запуск
```bash
cd Go52/opcode-install-quest
go run main.go
