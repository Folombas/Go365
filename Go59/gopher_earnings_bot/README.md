# GopherEarningsBot – Telegram-бот для учёта доходов и прокачки

**Модуль:** Go59/gopher_earnings_bot  
**Автор:** Гоша (участник Go365)  
**Дата:** 28 февраля 2026 года  

## Описание

Этот Telegram-бот помогает отслеживать заработанные деньги, получать EXP за каждое взаимодействие и просто поднимает настроение. Бот написан на Go с использованием библиотеки `go-telegram-bot-api`.

### Возможности

- Команды `/start`, `/help`, `/earn`, `/weather`, `/profile`.
- Инлайн-клавиатуры для быстрого выбора.
- Система опыта (EXP) и уровней (прогресс-бар в профиле).
- Хранение данных в памяти (для простоты, можно заменить на БД).

## Установка и запуск

1. Получите токен бота у [@BotFather](https://t.me/botfather).
2. Вставьте токен в `main.go` (переменная `BotToken`).
3. Соберите и запустите:

```bash
cd Go59/gopher_earnings_bot
go mod tidy
go run main.go
