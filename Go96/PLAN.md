- Для звуков можно использовать простые синусоидальные волны через `audio` пакет

- Для анимаций использовать линейную интерполяцию (lerp)
- Transposition table: `map[string]int` где ключ - хеш позиции
- Тесты: `board_test.go`, `puzzle_test.go`, `ai_test.go`
