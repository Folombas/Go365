## ✅ Выполненные задачи

### 1. Новые враги (5 типов)

**Barnacle (Враг 8):**
- Стационарный враг на платформах/структурах
- Атакует когда игрок рядом (расширяется)
- Можно топтать только в убранном состоянии
- Красные частицы при уничтожении

**Ladybug (Враг 9):**
- Летающий враг с фигурой-8 паттерном
- Быстрее чем Fly, более агрессивный
- Спавнится в воздухе (3 тайла от земли)
- Красные частицы с чёрными точками

**Snail (Враг 10):**
- Медленный бронированный враг
- Требует 2 топков или Star power
- Очень медленное движение (0.2 пикселя/кадр)
- Зелёно-коричневые частицы

**Worm (Враг 11):**
- Появляется из земли периодически
- Неуязвим когда скрыт в земле
- Цикл: 100 кадров виден / 100 скрыт
- Розовые частицы при уничтожении

**Fish (Враг 12):**
- Водный враг для будущих водных зон
- Плавает в воздухе (для будущих уровней)
- Движение по синусоиде
- Синие/циан частицы

### 2. Обновление системы частиц

**Добавлены уникальные эффекты для каждого врага:**

| Враг | Цвет частиц | Количество | Паттерн |
|------|-------------|------------|---------|
| Barnacle | Красно-оранжевый | 16 | Круговой взрыв |
| Ladybug | Красный | 18 | Всплеск вверх |
| Snail | Зелёно-коричневый | 14 | Медленный спад |
| Worm | Розовый | 16 | Круговой |
| Fish | Синий/Циан | 20 | Круговой широкий |

**Общий код частиц:**
```go
func (g *Game) spawnEnemyDefeatParticles(x, y float64, enemyType int)
```
- Уникальные цвета для каждого типа
- Разное количество частиц
- Разные паттерны разлёта
- Разное время жизни (28-50 кадров)

### 4. Улучшенный спавн врагов

**Логика спавна по мирам:**

| Мир | Новые враги | Вероятность |
|-----|-------------|-------------|
| 1 | Koopa, Barnacle | 85% / 15% |
| 2 | + Fly, Frog, Ladybug | 50% / 20% / 10% |

**Позиции спавна:**

### 5. Улучшенные коллизии

**Специальные правила для новых врагов:**

```go
// Barnacle - можно топтать только когда убран
if math.Sin(float64(enemy.animFrame)*0.2) > 0.5 {
    canStomp = false
}

// Snail - требует Star power или Big состояния
if !g.player.isInvincible && !g.player.isBig {
    canStomp = false
}

// Worm - можно топтать только когда появился
if enemy.animFrame%200 >= 100 {
    canStomp = false
}
```
