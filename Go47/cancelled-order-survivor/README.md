# Go47: Cancelled Order Survivor — логирование и regexp в действии

## 📌 Название модуля
**`cancelled-order-survivor`** — программа для логирования жизненных перипетий с использованием `slog` и парсинга сообщений об отмене с помощью `regexp`.

## 🎯 Описание
Этот модуль демонстрирует:
- **slog** — структурированное логирование событий в файл.
- **regexp** — поиск саркастичных сообщений по шаблону.
- **Файловый I/O** — сохранение статистики (дни без CapCut, количество отмен, XP).
- **Геймификацию**: XP за каждый день и за каждую отмену.

Каждый запуск:
1. Логирует все события дня (поездки, отмену, настроение).
2. Проверяет наличие сообщения об отмене через regexp.
3. Обновляет счётчик дней без CapCut (с 18.01.2026).
4. Начисляет XP.
5. Выводит легенду, мотиваторы и анонс DeepSeek V4.
