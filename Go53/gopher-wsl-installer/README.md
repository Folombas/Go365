# Go53: Gopher WSL Installer — установка OpenCode через go install

## 📌 Название модуля
**`gopher-wsl-installer`** — программа, встраивающая легенду дня, инструкцию по установке OpenCode через `go install` в WSL Ubuntu 24, а также подсчитывающая дни обучения и XP.

## 🎯 Описание
Этот модуль демонстрирует:
- Встраивание текстовых файлов через `go:embed`.
- Подсчёт дней с фиксированной даты (18.01.2026).
- Геймификацию: XP, уровни, достижения.
- Инструкцию по установке OpenCode через `go install` (с дополнительными утилитами).

Каждый запуск:
1. Выводит легенду дня (пельмени, тимлид, бакенбарды).
2. Считает дни обучения и XP (с бонусом за отказ от посылки).
3. Показывает разблокированные достижения.
4. Даёт пошаговую инструкцию по установке OpenCode в WSL.
5. Хвалит Гошу и напоминает про дисклеймер.

## 🚀 Запуск
```bash
cd Go53/gopher-wsl-installer
go run main.go
