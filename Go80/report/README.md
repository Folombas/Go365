## 🔧 Технические детали

### Новые структуры
```go
type PowerupType int

const (
    MushroomPower PowerupType = iota // Гриб
    StarPower                        // Звезда
    ExtraLifePower                   // Жизнь
)

type Powerup struct {
    x, y, vy, px float32
    powerType    PowerupType
    collected    bool
    animFrame    int
    onGround     bool
}
```

### Новые функции
- `updatePowerups()` — обновление бонусов (физика, сбор)
- `applyPowerup()` — применение эффекта бонуса
- `drawPowerups()` — отрисовка бонусов
- `drawUI()` — улучшенный интерфейс
