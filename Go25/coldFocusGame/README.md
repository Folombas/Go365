# ❄️ ColdFocus: The Go Coder's Survival Simulator

## 🎮 О проекте
**ColdFocus** - это интерактивная текстовая игра-симулятор, созданная для мотивации изучения языка программирования Go. Игрок берет на себя роль Гоши - начинающего программиста, который должен пережить холодный день и найти время для изучения Go, несмотря на многочисленные отвлекающие факторы.

## 📅 Сюжет
*25 января 2026 года, воскресенье. Гоша просыпается в ледяной комнате (балкон был открыт всю ночь). Ему предстоит пройти через все испытания дня: от пробуждения в холоде до вечернего программирования, избегая искушений в виде телевизора, соцсетей и прокрастинации.*

## 🎯 Цель игры
- Дожить до вечера с хорошими показателями здоровья и фокуса
- Заработать достаточно денег на такси
- Избежать отвлекающих факторов
- Изучить Go и повысить свой уровень знаний

## 🕹️ Управление
Игра разделена на 4 фазы:
1. **Утро** (11:00) - Пробуждение, умывание, завтрак
2. **День** (13:00-17:00) - Работа таксистом, поездки, магазин
3. **Вечер** (19:00-20:00) - Ужин, борьба с телевизором
4. **Ночь** (20:30+) - Программирование на Go

В каждой фазе доступны 4 действия. Выбирайте номер действия для выполнения.

## 👤 Характеристики игрока
- **❤️ Здоровье** - физическое состояние
- **🎯 Фокус** - способность концентрироваться
- **⚡ Энергия** - запас сил
- **🔥 Теплота** - защита от холода
- **🐹 Знание Go** - уровень владения языком
- **🛡️ Сила воли** - сопротивление искушениям
- **💰 Деньги** - финансовые ресурсы
