### 2. Разные парадигмы = ментальная каша

Ты пытаешься одновременно держать в голове **две несовместимые парадигмы**:

| Go (процедурная + композиция) | C# (объектно-ориентированная) |
|-------------------------------|-------------------------------|
| `type Player struct` | `class Player : GameObject` |
| `func (p *Player) Update()` | `public override void Update()` |
| `if err != nil { return err }` | `try { ... } catch (Exception e)` |
| `go routine()` | `async Task RunAsync()` |
| `chan data` | `TaskCompletionSource` |
| Композиция: `struct { Player }` | Наследование: `class Enemy : Player` |

**Что происходит в мозге:**
```
Go: "Нужно вернуть error"
C#: "Нужно бросить exception"
Go: "Стоп, а что мы используем?"
C#: "А где async/await?"
Go: "А как запустить конкурентно?"
C#: "А где Task.Run?"
🔥 МОЗГ ВЗРЫВАЕТСЯ 🔥
```

**Результат:**
- Пишешь код на Go с ошибками из C#
- Пишешь код на C# с ошибками из Go
- **Не прогрессируешь ни в одном языке**

## ✅ ВСЕ АССЕТЫ С opengameart.org РАБОТАЮТ С EBITENGINE!

### 🎨 PNG — универсальный формат

**Хорошая новость:** Все ассеты, которые ты скачал с opengameart.org для mario_monogame, **работают с Ebitengine без изменений!**

```
mario_monogame/assets/PNG/  →  go_mario/assets/
├── Players/                →  Спрайты игрока (алиены, кролики)
├── Enemies/                →  Враги (slime, bee, mouse, fish)
├── Items/                  →  Монеты, яблоки, бонусы
├── Tiles/                  →  Тайлы платформ
├── Backgrounds/            →  Фоны (grassland, desert, snow)
└── HUD/                    →  Интерфейс (жизни, очки)
```

### Пример загрузки в Ebitengine:

**C# MonoGame:**
```csharp
// mario_monogame.Core/MarioPlatformerGame.cs
_playerSprite = Content.Load<Texture2D>("Sprites/Players/128x256/Green/alienGreen_stand");
```

**Go Ebitengine:**
```go
// go_mario/main.go
playerSprite, err := ebitenutil.NewImageFromFile("assets/PNG/Players/128x256/Green/alienGreen_stand.png")
if err != nil {
    log.Fatal(err)
}
```

**Это проще!** Нет Content Pipeline, нет .mgcb файлов, нет сложностей.

| **Потребление памяти** | 20-50 MB | 100-200 MB | 🏆 Go |
| **Запуск** | < 1 секунды | 2-3 секунды | 🏆 Go |
| **Зависимости** | Никаких | .NET SDK, NuGet | 🏆 Go |
| **Экосистема** | Растущая | Зрелая | 🏆 C# |
| **Документация** | Лаконичная | Подробная | 🏆 C# |
| **Инструменты** | Простые (go fmt, go vet) | Мощные (ReSharper, VS Debugger) | 🏆 C# |
| **Порог входа** | Низкий (25 ключевых слов) | Средний (ООП концепции) | 🏆 Go |
| **Производительность** | Нативный код, минимальный GC | JIT, поколенческий GC | 🏆 Go |
| **Кроссплатформенность** | Отличная (включая WASM) | Хорошая (WASM ограничен) | 🏆 Go |

**Итог:** Для 2D инди-игр **Go + Ebitengine лучше** по простоте, производительности и удобству разработки.
