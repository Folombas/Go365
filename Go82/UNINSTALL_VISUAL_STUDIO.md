### ШАГ 1: Подготовка (5 минут)

```bash
# 1.1. Закрой все проекты
# - Сохрани изменения в mario_monogame (если есть)

# 1.2. Создай резервную копию (если жалко)
cd /home/gofer/godev/projects
tar -czvf mario_monogame_backup_$(date +%Y%m%d).tar.gz mario_monogame/

# Путь к архиву: /home/gofer/godev/projects/mario_monogame_backup_20260322.tar.gz
# Теперь можно удалять — архив останется
```

---

### ШАГ 2: Удаление Visual Studio (15 минут)

**Linux (если установлена через apt/snap):**

```bash
# Проверить установленные пакеты
dpkg --list | grep -i visual
dpkg --list | grep -i code

# Удалить Visual Studio Code (если хочешь полностью)
sudo apt remove code
sudo apt remove visual-studio-code

# Удалить остаточные файлы
rm -rf ~/.config/Code
rm -rf ~/.vscode

# Очистить кэш
sudo apt autoremove
sudo apt autoclean
```

**Windows:**

```
1. Открой "Панель управления"
2. "Программы и компоненты"
3. Найди "Microsoft Visual Studio 2022" (или 2023)
4. Правая кнопка → "Удалить"
5. Запусти Visual Studio Installer
6. Выбери "Удалить" для каждой версии
7. Перезагрузи компьютер
```

---

### ШАГ 3: Удаление .NET SDK (10 минут)

**Linux:**

```bash
# Найти установленные версии
dotnet --list-sdks

# Удалить .NET SDK 8.0
sudo apt remove dotnet-sdk-8.0
sudo apt remove dotnet-runtime-8.0

# Удалить полностью
sudo rm -rf /usr/share/dotnet
sudo rm -rf /etc/dotnet
sudo rm -rf ~/.dotnet

# Удалить из PATH (если добавлял)
nano ~/.bashrc
# Удали строки с dotnet
source ~/.bashrc
```

**Windows:**

```
1. "Панель управления" → "Программы и компоненты"
2. Найди ".NET SDK 8.0.x"
3. Удалить каждую версию
4. Найди ".NET Runtime 8.0.x"
5. Удалить каждую версию
6. Перезагрузи компьютер
```

---

### ШАГ 4: Удаление MonoGame (5 минут)

```bash
# Удалить пакеты MonoGame (если установлены)
sudo apt remove monogame

# Удалить проект mario_monogame (если решил удалять)
cd /home/gofer/godev/projects
rm -rf mario_monogame/

# Или оставить заархивированным (рекомендую)
# Архив уже создан в Шаге 1
```

### ШАГ 5: Очистка окружения (10 минут)

```bash
# Удалить ярлыки
rm ~/Desktop/Visual\ Studio*.desktop 2>/dev/null
rm ~/Desktop/MonoGame*.desktop 2>/dev/null

# Очистить меню приложений (Linux)

# Если нашлось — удалить из ~/.bashrc или ~/.zshrc

# Перезапустить терминал

# Открыть новый терминал
```

### ШАГ 4: Настройка Go

```bash
# Создать рабочую директорию
mkdir -p ~/go/src
mkdir -p ~/go/bin
mkdir -p ~/go/pkg

# Добавить в ~/.bashrc
echo 'export GOPATH=$HOME/go' >> ~/.bashrc
echo 'export PATH=$PATH:$GOPATH/bin' >> ~/.bashrc
source ~/.bashrc
```
