### 3. Улучшения go_mario (v0.3.0)

#### 3.1 Система ассетов

Добавлена структура `Assets`:

```go
type Assets struct {
    playerStand  *ebiten.Image
    playerWalk1  *ebiten.Image
    playerWalk2  *ebiten.Image
    playerJump   *ebiten.Image
    slimeGreen   *ebiten.Image
    slimeBlue    *ebiten.Image
    coinSprite   *ebiten.Image
}
```

Реализована функция `LoadAssets()`:
- Загружает спрайты из `assets/PNG/`
- Возвращает `nil` для отсутствующих файлов (fallback)
- Все загрузки безопасны (не ломают игру)

#### 3.2 Отрисовка игрока со спрайтами

Обновлена функция `drawPlayer()`:

**Логика выбора спрайта:**
- `!p.onGround` → спрайт прыжка
- `p.vx != 0` → анимация ходьбы (walk1/walk2)
- иначе → спрайт ожидания (stand)

**Особенности:**
- Анимация ходьбы (2 кадра, переключение по `animFrame/8`)
- Отрисовка с учётом направления (flip по X при facing=-1)
- Fallback на векторную графику если спрайты не загружены

#### 3.3 Отрисовка монет со спрайтами

Обновлена отрисовка в `drawLevel()`:
- Используется спрайт `coinGold.png`
- Анимация покачивания (sin offset)
- Fallback на векторные круги

#### 3.4 Отрисовка врагов со спрайтами

Добавлена функция `drawEnemies()`:

**Выбор спрайта по типу:**
- `EnemyGoomba` → `slimeGreen`
- `EnemyKoopa` → `slimeBlue`

**Особенности:**
- Отрисовка с учётом направления (flip)
- Пропуск мёртвых врагов (!alive)
- Пропуск внеэкраных врагов (оптимизация)
- Fallback на векторные прямоугольники

## 🔍 Анализ: Go vs C# для 2D игр

### Go + Ebitengine

**Преимущества:**
- Простота: 3 функции (Update, Draw, Layout)
- Компиляция < 1 секунды
- Один бинарник 10-15 MB
- Потребление памяти 20-50 MB
- Никаких зависимостей (.NET runtime)
- Отличная кроссплатформенность (включая WASM)

**Недостатки:**
- Меньше готовых библиотек
- Меньше туториалов
- Нет визуальных редакторов

### C# + MonoGame

**Преимущества:**
- Зрелая экосистема
- Много туториалов и примеров
- Мощные инструменты (Visual Studio, ReSharper)
- Визуальные редакторы

**Недостатки:**
- Сложная иерархия классов
- Компиляция 5-10 секунд
- Бинарник 50-100 MB с runtime
- Потребление памяти 100-200 MB
- Зависимость от .NET SDK/runtime

### Вывод

Для 2D инди-игр **Go + Ebitengine лучше** по:
- Простоте разработки
- Производительности
- Размеру дистрибутива
- Удобству деплоя
