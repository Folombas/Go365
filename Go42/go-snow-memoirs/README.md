# Go42: CapCut Snow Memoirs — I/O и файловое хранение достижений

## 📌 Название модуля
**`capcut-snow-memoirs`** — программа для учёта дней без CapCut с сохранением прогресса в JSON.

## 🎯 Описание
В день 42 Гоша переживает снежную депрессию, но продолжает обучение.
Программа демонстрирует **работу с файловой системой в Go**:
- Чтение и запись JSON-файлов.
- Обработка ошибок при работе с файлами.
- Структуры и сериализация.
- Работа с датами и временем.

Каждый запуск:
1. Загружает файл `gosha_snow_memoirs.json` (или создаёт его).
2. Вычисляет количество дней с 18.01.2026.
3. Проверяет новые достижения.
4. Начисляет XP, обновляет слоган дня.
5. Сохраняет обновлённые данные.
6. Выводит снежную легенду, статистику, мотиваторы.
