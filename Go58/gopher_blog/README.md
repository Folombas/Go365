# Gopher's Journey — личный блог Go-разработчика

**Модуль:** Go58/gopher_blog  
**Автор:** Гоша (участник Go365)  
**Дата:** 27 февраля 2026 года  

## Описание

Gopher's Journey — это полноценный веб-блог, написанный на чистом Go (стандартная библиотека `net/http`), с ванильным JavaScript и современным CSS-дизайном. Блог позволяет:

- Просматривать список всех постов.
- Читать отдельные записи.
- Добавлять новые посты (пока без авторизации, для личного использования).
- Накапливать EXP и повышать уровень за каждую опубликованную запись.
- Получать достижения за количество постов.

## Требования

- Go 1.16 или выше
- Порт 8080 свободен
