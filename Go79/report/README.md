### 5. Звуковые эффекты и кровь (v0.7.0)

#### 🎵 Аудиосистема
**9 программируемых звуков:**

| Звук | Описание | Длительность |
|------|----------|--------------|
| 🔊 Eat Food | Короткий "чпок" | 0.1 сек |
| 🔔 Collect Coin | Высокий "динь" с вибрато | 0.2 сек |
| 🔑 Collect Key | Звонкий (две гармоники) | 0.15 сек |
| 🏴‍☠️ Open Chest | "Бум" + звон монет | 0.3 сек |
| 🏹 Shoot | Быстрый свист | 0.15 сек |
| 💣 Explosion | Низкий грохот | 0.4 сек |
| 🎁 PowerUp | Восходящий арпеджио | 0.3 сек |
| 💀 Enemy Kill | Неприятный скрежет | 0.2 сек |
| ☠️ Game Over | Нисходящий грустный | 0.5 сек |

**Технические детали:**
- Sample rate: 44100 Гц
- Формат: 16-bit stereo
- Программная генерация (без внешних файлов)
- Громкость: 0.3 (настраиваемая)

#### 🩸 Система крови

**BloodParticle:**
- Физика с гравитацией (0.2)
- Начальный импульс вверх
- 15-25 жизней (0.25-0.4 сек)
- Размер: 2-5 пикселей
- Цвет: тёмно-красный (180, 0, 0)

**BloodStain:**
- Остаётся после падения частицы
- Длительность: 300 кадров (5 сек)
- Полупрозрачный (alpha 180)
- Исчезает постепенно

**Эффекты:**
- 20 частиц крови при убийстве врага
- Брызги в направлении удара
- Пятна остаются на земле

#### 🏹 Улучшенная стрельба

**Изменения:**
- Скорость стрелы: 2 тика (было 3)
- Урон: 1 единица
- Кровь при попадании во врага
