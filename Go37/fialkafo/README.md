# 🚚 FialkaFO: Год в Go Logistics

## Модуль 37 дня марафона "100DaysGo: Reboot"

### 📖 Сценарий: "Год в диспетчерской фур-горутин"

Гоша уже целый год работает диспетчером в транспортно-логистической компании **"Fialka FO - Go Logistics"**.
Он управляет фурами-горутинами, распределяет грузы-данные по каналам-дорогам,
и каждый день делает выбор: остаться с Go или перейти в другую компанию.

### 🎯 Суть модуля

Программа-симулятор года работы Go-разработчика через метафору логистической компании:

- **Фуры** = горутины Go
- **Грузы** = задачи/данные
- **Дороги** = каналы (channels)
- **Диспетчерская** = управляющий код
- **Другие компании** = другие языки программирования

### 🏢 Мир IT-компаний 2026

Каждая компания представляет собой метафору языка/технологии:

| Компания | Язык/Технология | Метафора |
|----------|-----------------|----------|
| 🚚 **Go Logistics** | Go | Транспортная логистика с фурами-горутинами |
| 🛤️ **Java Trails** | Java | Железные дороги с мощными составами |
| 🔧 **Rust Garage Lab** | Rust | Гараж-лаборатория для вездеходов |
| 🌿 **Python Data Gardens** | Python | Теплицы для выращивания данных |
| 🎪 **JavaScript Circus** | JavaScript | Динамичный цирк-шапито |
| 🏭 **C++ Foundry** | C++ | Литейный цех высокооптимизированных движков |

### 🎮 Игровая механика

#### Прокачка персонажа:
- **Go XP** — опыт работы с Go (растет с каждой доставкой)
- **Капитал** — заработанные деньги (успешные доставки)
- **Рейтинг компаний** — динамическая оценка каждой "компании-языка"

#### События:
- Ежедневная доставка грузов (задачи)
- Сбои и проблемы (туман, поломки, пробки)
- Предложения от других компаний (каждые 30 дней)
- Чат диспетчерской (история событий)

#### Принятие решений:
Каждый месяц Гоша получает заманчивые предложения от других компаний,
но каждый раз выбирает остаться с Go Logistics.
