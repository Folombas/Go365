# 🎭 Canceled Boots Drama (Упрощенная версия)

> *"Один файл — одна драма. Как и в жизни."*

## 📖 О программе
Это минималистичный симулятор дня курьера-разработчика Гоши, умещенный в **один файл main.go**. Всего 2 файла в модуле:
+ `main.go` - вся программа
+ `README.md` - эта документация

## 🎯 Суть драмы
*17 января 2026. Гоша отменяет заказ с ботинками из дома по телефону. Но потом идёт пешком через МКАД в Химки, забирает два заказа, едет на новом автобусе... Каждое решение влияет на его "дофаминовый баланс" — внутреннюю валюту мотивации программиста.*

## 🚀 Как запустить
```bash
# Перейдите в папку модуля
cd Go17/canceled-boots-drama

# Запустите программу
