## 🎮 Игровой процесс

### Начало игры
```
1. Игрок заходит на сайт
2. Создаётся уникальный user_id (localStorage)
3. Создаётся игрок с начальными характеристиками
4. Создаётся дерево навыков (12 навыков)
5. Создаются квесты (5 квестов)
6. Создаются достижения (23 достижения)
7. Применяются начальные бонусы
```

### Викторина
```
1. Игрок нажимает "🚀 Начать"
2. Загружается случайный вопрос
3. Игрок выбирает вариант ответа
4. При правильном ответе: +EXP, +Знание Go
5. При неправильном: прогресс не меняется
6. После ответа: кнопка "Далее →"
```

### Улучшение навыков
```
1. Игрок переходит на страницу "🌳 Навыки"
2. Видит доступные навыки с кнопками "⬆️ Улучшить"
3. Нажимает кнопку (если хватает очков)
4. Навык улучшается, бонус применяется
5. Характеристики игрока обновляются
```

### Квесты
```
1. Игрок выполняет действия (викторина, изучение Go)
2. Прогресс квестов обновляется автоматически
3. При выполнении: кнопка "🎁 Забрать"
4. Игрок забирает награду (очки навыков)
```

### Достижения
```
1. Игрок выполняет условия (уровень, квесты, время)
2. При загрузке статистики проверяются достижения
3. Разблокированные отображаются с иконкой
4. Заблокированные показываются с 🔒
```
