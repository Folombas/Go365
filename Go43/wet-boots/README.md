# Go43: Wet Boots Resistance — JSON-дневник

## 📌 Название модуля
**`wet-boots-resistance`** — программа для учёта дней без CapCut с сохранением прогресса в JSON и метафорой мокрых ботинок.

## 🎯 Описание
В пятницу 13 февраля 2026 года Гоша встаёт рано, покупает проездной, промокает в нубуковых ботинках, но продолжает учить Go.
Этот модуль демонстрирует:
- **Чтение и запись JSON** (`encoding/json`, `os`).
- **Структуры и сериализацию**.
- **Обработку времени** (`time`).
- **Геймификацию**: достижения, XP, уровень промокания.

Каждый запуск:
1. Загружает файл `wet_boots_resistance.json` (или создаёт его).
2. Вычисляет количество дней с 18.01.2026.
3. Проверяет новые достижения (1, 7, 13, 30, 43, 60, 100 дней).
4. Начисляет XP (+43 за каждое новое достижение).
5. Обновляет «уровень промокания» (дни/7).
6. Сохраняет данные обратно в JSON.
7. Выводит легенду дня, статистику, мотиваторы, похвалу.
