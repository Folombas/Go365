## 🎯 Цель модуля

Показать через трагикомичный код:
1. Важность фокуса в обучении
2. Цену отвлечений
3. Долгосрочную пользу инвестиций в навыки
4. Психологическую борьбу при самообучении

## 🕹️ Игровая механика

### Характеристики персонажа:
- **Go XP** — опыт в Go (нужен для повышения уровня)
- **Фокус** — способность концентрироваться (истощается при обучении)
- **Мотивация** — желание продолжать (падает при работе курьером)
- **Уровень** — текущий скилл разработчика
- **Кошелек** — текущие финансы

### Основные действия:
1. **Учить Go** — увеличивает XP, уменьшает фокус
2. **Отдыхать** — восстанавливает фокус и мотивацию
3. **Работать курьером** — дает деньги, но убивает мотивацию

### Отвлекающие факторы:
- CapCut и видео-монтаж
- Воспоминания о прошлых отпусках
- Соцсети и прокрастинация
- Финансовая тревожность
