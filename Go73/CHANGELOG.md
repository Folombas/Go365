- 💎 Бонусы (зелёные сферы)

---

### 3. Игровая механика

**Управление:**
```
WASD / Стрелки — Движение
Space — Ускорение (boost)
```

**Система:**
- ❤️ Health: 100 HP, -20 при столкновении
- 📊 Score: +10 за врагов, +50 за бонусы
- 📈 Level: растёт каждые 100 очков
- 🔥 Комбо: множитель x1.0 → x1.5 → x2.0...
- ⚡ Сложность: спавн учащается с уровнем

**Бонусы:**
- 🟢 Зелёные сферы: +50 очков

### 5. Go Backend

**API Endpoints:**

| Method | Endpoint | Описание |
|--------|----------|----------|
| GET | `/health` | Health check |
| GET | `/api/leaderboard` | Получить топ-10 |
| POST | `/api/leaderboard` | Сохранить счёт |

**Модель Score:**
```go
type Score struct {
    ID        int64     `json:"id"`
    Name      string    `json:"name"`
    Score     int       `json:"score"`
    CreatedAt time.Time `json:"created_at"`
}
```

**Storage (SQLite):**
```sql
CREATE TABLE scores (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    score INTEGER NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

**Middleware:**
- Logger
- Recoverer (panic handling)
- CORS (для разработки)
