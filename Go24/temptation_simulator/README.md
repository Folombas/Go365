# 🎮 Temptation Simulator 2.0

**Симулятор борьбы с искушениями в процессе изучения Go**

---

## 📖 Описание

Temptation Simulator — это мотивационная игра-симулятор, где вы играете за Гошу, 
который учится на Go-разработчика, работая курьером. Ваша цель — сопротивляться 
искушениям, изучать Go и достичь уровня, достаточного для устройства в офис.

---

## 🎯 Особенности версии 2.0

### 🌳 Дерево навыков
- **12 уникальных навыков** в 4 категориях:
  - 📚 Go-навыки: Основы Go, Конкурентность, Интерфейсы, Web Фреймворки, Базы данных, Микросервисы, Чистая архитектура
  - 🎯 Фокус: Мастер Фокуса, Медитация, Борьба с прокрастинацией
  - 💪 Сила воли: Сила Воли, Дисциплина, Холодный душ
  - 💰 Финансы: Управление деньгами

### 📋 Ежедневные квесты
- 5 случайных квестов каждый день
- Награды в виде очков навыков
- Система серий (day streak)
- Примеры квестов:
  - "30 минут Go" — изучи новую тему
  - "Борец с искушениями" — сопротивляйся 3 искушениям
  - "Практика кода" — напиши 50+ строк кода

### 📊 Система уровней и статистики
- Опыт за изучение Go и сопротивление искушениям
- Повышение уровня с наградами
- Расширенная статистика игры
- Рейтинговая система (от "Начинающего гофера" до "Senior Go Master")

### 💾 Система сохранений
- Автосохранение прогресса
- JSON файлы сохранений в папке `saves/`
- Загрузка предыдущих игр
- Полная сериализация состояния игрока

### 👹 Босс-искушения
- 5 особо опасных боссов:
  - 👹 CAPCUT МОНТЁР (сила 95)
  - 👹 ИГРОВОЙ ЗАВИСИМОН (сила 92)
  - 👹 СОЦСЕТЕЙ ДЕМОНИУС (сила 88)
  - 👹 АЛКОГОЛЬНЫЙ ПРИЗРАК (сила 90)
  - 👹 ДЕПРЕССИЯ МАКСИМА (сила 98)

### 🎮 Игровой процесс
- 16 игровых часов = 1 день
- Интерактивное меню с выбором действий
- Случайные события (искушения, мотивация, боссы)
- Балансировка между учёбой, отдыхом и борьбой с искушениями

## 🚀 Запуск

```bash
cd Go24/temptation_simulator
go run .
```

Или скомпилируйте:

```bash
go build -o temptation_simulator .
./temptation_simulator
```

## 🎮 Управление

### Главное меню
1. **Новая игра** — начать новую игру
2. **Загрузить игру** — продолжить сохранение
3. **О игре** — информация
4. **Выход** — выйти из игры

### Игровое меню
1. 📚 **Учить Go** — сессия изучения (получение опыта)
2. 📋 **Проверить квесты** — просмотр прогресса
3. 🌳 **Дерево навыков** — улучшение навыков
4. 💤 **Отдохнуть** — восстановление фокуса
5. 📊 **Статистика** — расширенная статистика
6. 💾 **Сохранение** — управление сохранениями
7. 🌙 **Завершить день** — переход к финальной битве
8. 🚪 **Сохранить и выйти** — выход с сохранением

## 🛠️ Технические детали

### Структура проекта
```
temptation_simulator/
├── main.go           # Главный файл, игровое меню
├── player.go         # Персонаж, статы, уровни
├── game.go           # Игровая логика, сессии
├── skills.go         # Дерево навыков, квесты
├── temptation.go     # Искушения, мотивация
├── achievements.go   # Система сохранений
└── .gitignore        # Игнорирование бинарников
```

### Сохранения
Сохранения создаются в папке `saves/` в формате JSON:
```json
{
  "player": { ... },
  "skill_tree": { ... },
  "quests": { ... },
  "game": { ... }
}
```
