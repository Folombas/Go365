# Go44: Valentine Lonely Dev — I/O дневник прокачки

## 📌 Название модуля
**`valentine-lonely-dev`** — программа для ведения дневника событий с сохранением в JSON и подсчётом дней без CapCut.

## 🎯 Описание
В День святого Валентина Гоша остаётся один, но не унывает: идёт в барбершоп, закупает продукты, ест беляши и пишет код.
Этот модуль демонстрирует:
- **Чтение и запись JSON** (`encoding/json`, `os`).
- **Добавление записей в массив и сохранение**.
- **Подсчёт дней с фиксированной даты**.
- **Геймификацию**: XP за бытовые действия, уровни.

Каждый запуск:
1. Загружает файл `valentine_journal.json` (или создаёт новый).
2. Создаёт запись сегодняшнего дня с событиями.
3. Начисляет XP за стрижку, фото, покупки, беляши и планы.
4. Сохраняет обновлённый журнал.
5. Выводит легенду дня, статистику прокачки, мотивационные фразы и похвалу.
