# Go41: Race Patrol — детектор гонок в промзоне

## 🎯 Название модуля
**`race-patrol`** — патруль по выявлению состояний гонки в конкурентном коде, вдохновлённый прогулкой по промзоне и истекшим проездным.

## 📖 Легенда
Сегодня ты остался без проездного — как без мьютекса в многопоточной среде.
Ты гуляешь по промзоне, чистишь картошку, пылесосишь и одновременно учишь Go.
Каждая горутина — прохожий, каждый общий ресурс — картофелина или место у окна в трамвае.
Гонка данных возникает, когда несколько горутин одновременно пытаются изменить одну переменную.
Детектор гонок Go (`-race`) ловит таких нарушителей мгновенно.

## 🧠 Что внутри?
- **Гонка в трамвае** — 10 горутин без синхронизации борются за счётчик мест.
- **Чистка картошки** — мьютекс защищает общий ресурс.
- **Атомарный пылесос** — атомарный счётчик без блокировок.
- **Система достижений** — прокачка персонажа за каждый пройденный этап.
- **10 мотивационных истин** — чтобы не свернуть с пути Go.

## 🚀 Быстрый старт
```bash
cd Go41
go run main.go          # Увидишь неправильный результат гонки
go run -race main.go    # Детектор покажет WARNING: DATA RACE
