## ✅ Выполнено

### Сервер (Go)

**Файл:** `server/main.go`

**Функции:**
- REST API с 3 эндпоинтами
- SQLite для хранения прогресса
- CORS middleware
- Логирование запросов
- Раздача статических файлов

**Эндпоинты:**
| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/api/save` | Сохранение прогресса |
| GET | `/api/progress` | Загрузка прогресса |
| GET | `/api/leaderboard` | Топ-10 игроков |

### Клиент (Phaser 3)

**Структура:**
```
client/
├── index.html
├── src/
│   ├── api.js — API модуль
│   ├── main.js — точка входа
│   ├── objects/
│   │   ├── Player.js
│   │   ├── Enemy.js
│   │   └── Collectible.js
│   ├── scenes/
│   │   ├── Boot.js
│   │   ├── Menu.js
│   │   ├── Level.js
│   │   └── Victory.js
│   └── ui/
│       └── HUD.js
```

**Сцены:**

1. **BootScene** — загрузка ассетов
   - Программная генерация спрайтов
   - Создание тайлсетов
   - Прогресс-бар загрузки

2. **MenuScene** — карта уровней
   - Древо технологий (5 узлов)
   - Визуализация прогресса
   - Таблица лидеров
   - Выбор уровня

3. **LevelScene** — игровой процесс
   - Физика Arcade
   - 6 уникальных уровней
   - Враги (баги, вирусы, ошибки, файрволы)
   - Кристаллы (обычные, синие, фиолетовые)
   - Портал (открывается после сбора всех кристаллов)
   - Заклинания (фаербол на F)
   - HUD (HP, MP, кристаллы, счёт)

4. **VictoryScene** — завершение уровня
   - Статистика (кристаллы, время, счёт)
   - Рейтинг (1-3 звезды)
   - Конфетти
   - Кнопки продолжения

**Объекты:**

| Объект | Описание |
|--------|----------|
| Player | Фиолетовый лорд, здоровье, мана, заклинания |
| Enemy | 4 типа врагов с разными характеристиками |
| Collectible | 5 типов предметов (кристаллы, здоровье, мана) |

## 🎮 Геймплей

**Управление:**
- **A/D** или **←/→** — движение
- **W/↑/SPACE** — прыжок
- **F** — заклинание (фаербол)
- **ESC** — пауза

**Механики:**
- Сбор кристаллов для открытия портала
- Уничтожение врагов прыжком по голове или заклинанием
- Избегание падения в пропасть
- Сбор бонусов (здоровье, мана)
