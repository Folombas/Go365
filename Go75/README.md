# Simple Snake - Go365 Go75

Классическая игра Змейка на Go с использованием фреймворка **Ebitengine**.

## Запуск

```bash
go run main.go
```

## Управление

- **Стрелки** — движение змейки
- **Enter** — перезапуск после проигрыша

## Особенности

- Сетка 20x20 клеток
- Змейка растёт при поедании пищи
- Столкновение со стеной или хвостом = проигрыш
- Подсчёт очков

## Скриншот

Зелёная змейка, красная еда, чёрный фон.
