## ✅ Выполненные задачи

### 1. Тайлы со спрайтами

**Загружены спрайты для всех типов тайлов:**

```go
// В структуре Assets добавлено:
grassTile    *ebiten.Image  // grass.png
brickTile    *ebiten.Image  // brickGrey.png
questionTile *ebiten.Image  // boxItem.png
hardTile     *ebiten.Image  // brickBrown.png
pipeTile     *ebiten.Image  // lockGreen.png
usedTile     *ebiten.Image  // boxItem_disabled.png
```

**Обновлена функция `drawTile()`:**
- Сначала пытается отрисовать спрайт
- Fallback на векторную графику если спрайт не загружен
- Все тайлы теперь используют реальные изображения

**Источники тайлов:**
- `assets/PNG/Ground/Grass/grass.png` — земля с травой
- `assets/PNG/Tiles/brickGrey.png` — кирпич
- `assets/PNG/Tiles/boxItem.png` — вопрос-блок
- `assets/PNG/Tiles/brickBrown.png` — твёрдый блок
- `assets/PNG/Tiles/lockGreen.png` — труба
- `assets/PNG/Tiles/boxItem_disabled.png` — использованный блок

### 2. Анимация врагов

**Добавлены 2 кадра анимации для каждого врага:**

```go
// В структуре Assets добавлено:
slimeGreen1  *ebiten.Image  // кадр 1
slimeGreen2  *ebiten.Image  // кадр 2
slimeBlue1   *ebiten.Image  // кадр 1
slimeBlue2   *ebiten.Image  // кадр 2
bee1         *ebiten.Image  // кадр 1
bee2         *ebiten.Image  // кадр 2
```

**Обновлена функция `drawEnemies()`:**
- Анимация переключается по `enemy.animFrame / 10 % 2`
- Чётные кадры → первый спрайт
- Нечётные кадры → второй спрайт
- Плавное переключение ~10 FPS

---

### 3. Звуковые эффекты

**Реализована функция `generateBeep()`:**
- Генерирует синусоидальный звук
- Частота и длительность настраиваются
- Огибающая (envelope) для плавного затухания
- Формат: 16-bit PCM, 44100 Hz

**Реализована функция `playSound()`:**
- 10 типов звуков с разными частотами:

| Звук | Частота | Длительность |
|------|---------|--------------|
| Jump | 400 Hz | 0.1 сек |
| Coin | 1200 Hz | 0.15 сек |
| Stomp | 200 Hz | 0.08 сек |
| Hit | 150 Hz | 0.2 сек |
| Die | 100 Hz | 0.5 сек |
| Powerup | 800 Hz | 0.3 сек |
| Bump | 100 Hz | 0.05 сек |
| Break | 80 Hz | 0.1 сек |
| Start | 600 Hz | 0.2 сек |
| Win | 800 Hz | 0.4 сек |

**Использование в игре:**
- `playSound(SoundJump)` — при прыжке игрока
- `playSound(SoundCoin)` — при сборе монет
- `playSound(SoundStomp)` — при уничтожении врага
- `playSound(SoundHit)` — при получении урона
- `playSound(SoundWin)` — при победе
- `playSound(SoundStart)` — при старте игры
